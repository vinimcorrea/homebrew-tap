# vinimcorrea/homebrew-tap

Homebrew casks for [vinimcorrea](https://github.com/vinimcorrea)'s apps.

```bash
brew install --cask vinimcorrea/tap/github-float
```

| Cask | App |
|---|---|
| `github-float` | [GitHub Float](https://github.com/vinimcorrea/github-float): an always-on-top macOS panel for your GitHub Project reviews |

The casks are updated automatically when a new release is published.
